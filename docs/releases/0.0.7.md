## Installation

Requires macOS 26 or later and Apple silicon.

Download `slime-0.0.7-arm64.dmg` and `slime-0.0.7-arm64.dmg.sha256`, then verify:

```sh
shasum -a 256 -c slime-0.0.7-arm64.dmg.sha256
```

Open the DMG and drag slime to Applications. The app is self-signed and not
notarized by Apple. If macOS blocks it, use **System Settings → Privacy & Security
→ Open Anyway** for slime. Grant Accessibility permission and restart; Screen
Recording permission is optional and enables window previews. DMG users do not
need to run signing or build scripts.

## Known limitations

- Background previews illustrate opaque colors; the actual appearance depends on glass strength and the desktop behind the panel. At 100% strength, the base background color is fully transparent.
- Some offscreen or other-Space windows may be unavailable, and cached previews can be stale. slime refuses to close a window when its identity cannot be determined reliably.
- Search supports typing and deleting from the end; text selection, arbitrary caret placement, and IME composition are not supported.
- This release provides an Apple silicon DMG only; no validated Intel package is included.
