# 0.0.5 实施顺序

关联 #47；基线为合并 spec 的 main `2fba010`。

1. 修饰键与会话生命周期：Trigger / EventTap / PanelWindow，先复现 ⌥Tab → ⌘，再锁定结束、失焦、停用后的原生放行。
2. 固定五列、分组行与导航：GridLayout / PanelController / CardGridView；搜索及刷新按窗口身份保持选择。
3. 设置与系统集成：Settings / SettingsWindow / AppDelegate，英文默认、双语、总开关、登录项、About。
4. 卡片圆角与占位、高亮动画；真实图片区域裁切，Reduce Motion 降级。
5. 精准窗口关闭与 CRT：唯一目标、后台 AX、结果确认、保存确认/失败恢复、异步会话隔离。
6. 本地测试与构建、原生界面验证、文档同步、PR 与当前 head CI 自审。用户合并。

测试沿用 spec 指定的公开接口；追加 EventTap 事件投递测试以覆盖 tap/面板生命周期，窗口关闭匹配与结果状态通过实际调用的纯函数测试。真实 AX、登录项与动画另记机器验证。

分组高度采用已合并提案：固定宽度、分区按内容增高至滚动上限。五列的卡片尺寸在原生截图里校准，保留和旧 240×176 的对照。
