# slime 0.0.5 — 界面、设置与窗口关闭

- **状态**：草案；交互方向已确认，当前只完成 spec，尚未开始正式实现
- **相关 issue**：#48（本 spec）；#47（后续实现）

## 目标

固定五列的平静、扁平化窗口面板；完整的基础设置；保留模式下可靠的 Command 快捷键；只关闭选中窗口的 CRT 动效。

## 非目标

不加入快捷键自定义、窗口级 MRU、鼠标点选或第三方依赖。本版先完成用户明确列出的操作链路。

## 背景与约束

以 main 0ba5a1a（PR #46）为基线。Swift 6 / AppKit / macOS 26+。事件 tap 不阻塞；AX 后台执行且有超时；系统原生快捷键兜底保持有效。合并由用户执行。

参考 Apple 当前设计资料：

- https://developer.apple.com/videos/play/wwdc2025/219/ ：内容优先、克制使用玻璃、适配减少动态效果。
- https://developer.apple.com/documentation/servicemanagement/smappservice/register() ：登录项注册可能需要系统批准。
- https://developer.apple.com/documentation/applicationservices/kaxclosebuttonattribute ：关闭具体窗口走其 AX 关闭按钮。

## 方案

### 面板

- 窗口预览使用约 **10pt 圆角**，高亮底色使用约 **14pt 圆角**，面板外层默认约 **20pt 圆角**。数值为视觉提案，真机验收后校准；预览图片本身必须裁切到圆角，不只给外容器画圆角。保留完整窗口比例，不为填满圆角矩形拉伸或裁掉内容；图标回退沿用相同卡片几何。这里改变的是 slime 内的预览，不改变目标应用的真实窗口形状。
- 固定五列宽。未分组时，0–5 项保留相同的一行面板尺寸，6 项换行；最多三行可视，更多滚动。搜索到少量结果也不缩窄。初定卡片 200×160pt、间隔 12pt、外边距 20pt、搜索区 52pt，对应宽 1088pt、一行高 252pt。窄屏按可用宽度等比例缩小预览区，标题保留可读字号，仍保持五列；总高度也不得超出当前显示器可用区域。
- 分组时固定五列宽，但高度按分区内容增长，达到可视上限后滚动；这是针对「每组另起一行」的布局提案，见未决问题。
- 取消高亮粗边框。用户已选择「淡色背景 + 动态短下划线」；同一行指示条平滑滑动，跨行淡出淡入，不斜穿缩略图。
- 同行高亮移动初定 160–200ms，以平滑减速收尾；跨行初定 100–140ms 淡出淡入。淡色背景在旧/新卡片之间交叉淡化，只有下划线做横向位移，避免整块色块掠过预览。
- 连续 Tab 时从动画的当前呈现位置重新定向，不排队等待。启用 Reduce Motion 时直接更新/短淡化，不收缩闪烁。
- 分组默认关闭。用户开启后，同一 app 独立分区，每组另起一行，带图标和 app 名；每行最多五张。关闭后连续排列，保留既有 app 聚拢排序。
- 搜索保留模糊匹配；分组开启时组内按匹配结果，组顺序按结果中的首次出现。方向键跨实际占用的行，不选中空槽或组标题。

### 截图参考：圆角与无预览占位（2026-10-13 补充）

用户提供的参考：`~/Desktop/glide-example.png`（Glide3 窗口切换面板）。第二排「Pull requests • chriscco/slime」卡片可见灰色标题栏、三颗圆点、数条内容示意线和居中的 Chrome 图标，右下角另有应用角标。视觉上属于通用窗口示意占位；截图不能证明对方采用了何种抓取、缓存或绘制实现。

**圆角层次**：参考其外卡片与内部预览的嵌套关系，沿用预览约 10pt、高亮底色约 14pt、面板约 20pt 的提案。内外轮廓间保留均匀留白；真实缩略图按比例缩放后，对实际图片显示区域裁切圆角，避免只裁切外层容器、图片缩在其中仍显直角。横向、纵向和窄窗口都使用同一规则。高亮仍为已确认的淡色背景加动态短下划线。

**无预览时的小窗口占位**：

- 显示优先级：该窗口最新有效预览 → 该窗口已有的好图缓存 → 通用小窗口占位。保持既有抓取与持久化策略。
- 占位与正常预览使用同样的外框尺寸、圆角和标题位置；内部绘制低对比度的窗口底板、简化标题栏、三颗装饰圆点和 2–3 条静态内容线，中央显示真实应用图标（初定 32–40pt，不拉伸模糊）。Chrome、编辑器、终端等复用同一个形状，区别仅为应用图标。
- 卡片标题仍来自真实窗口标题（为空时回退 app 名）。占位只表达所属应用，不模拟具体网页、不拼装虚构内容，也不借用同 app 另一窗口的预览。辅助功能描述和悬停提示注明「Preview unavailable / 无法获取预览」。
- 示意线是静态装饰，不做骨架屏扫光或加载动画：无法抓取可能长期存在，不应暗示正在等待加载。
- 无屏幕录制权限、抓取失败且无缓存、首次遇到未渲染窗口，均使用此占位；应用图标取不到时复用现有通用图标回退。
- 为避免同一张占位里重复展示两个 app 图标，slime 暂只保留居中图标，不额外复制参考图的右下角图标。是否给真实预览统一增加应用角标不在本轮补充范围。
- 占位直接用 AppKit/Core Animation 几何图形及现有 AppIcons 绘制；无需图片素材、网页抓取或浏览器专用依赖。占位与真实预览同样参与 CRT 关闭动画。

**补充验收**：强制无预览且无缓存时，Chrome 卡片显示带 Chrome 图标的小窗口，标题仍是目标窗口的真实标题；有缓存时继续显示同一窗口的缓存。无权限时所有卡片布局保持一致。纵向与横向预览四角都被正确裁切；占位不出现持续加载动效，取得好图后在原卡片内更新，选中与布局不跳动。

### 设置

左侧导航：General / Appearance / Shortcuts / About。

- 总开关默认开。关闭后立即关闭面板、释放快捷键接管；菜单栏仍可访问设置，重启保留状态。重新开启无需重启。
- General：总开关、app 分组、登录时启动、English / 简体中文。布尔项使用原生开关控件，附简短说明。总开关关闭不清空外观、语言或分组偏好。
- 登录启动使用 SMAppService.mainApp，默认不主动注册，以系统实际状态为准；失败和待批准状态明确展示。
- 默认语言 English，包含从旧版本升级且未选择语言的用户。选择中文后菜单栏、面板、设置、权限提示与错误文案随之更新；保存偏好。
- Appearance：保留玻璃样式（Regular / Clear）、强度、面板圆角和高亮颜色。旧偏好保留；新默认面板圆角 20pt，强度仍为 20%。预览圆角与高亮圆角固定，不额外增加三个滑块。
- Shortcuts：只读展示实际支持的键盘操作，不提供录入/重绑定控件。

| 操作 | 快捷键 |
|---|---|
| 快速切换，松开 Command 确认 | ⌘Tab |
| 打开并保留面板 | ⌥Tab |
| 后一项 / 前一项 | Tab / ⇧Tab |
| 按卡片 / 按行移动 | ← → / ↑ ↓ |
| 输入过滤 / 删除末字符 | 直接键入 / Backspace |
| 保留面板并搜索 | ⌘F（按住 Option 时也支持 ⌥F） |
| 切到选中窗口 | Enter |
| 关闭选中窗口 | ⌘D |
| 打开设置 | ⌘,（按住 Option 时也支持 ⌥,） |
| 取消，不改变当前窗口 | Esc |

- About：读取 bundle 版本 0.0.5，链接 https://github.com/chriscco/slime。

### 键盘

⌥Tab → 松开 ⌥ → 按 ⌘ 不关闭面板、不清空 query、不重置选中。⌘, 打开设置，⌘F 保持搜索，⌘D 关闭高亮窗口。保留模式内 Tab 继续导航，松 ⌘ 不自动切换；退出后下一次快捷键正常开启新会话。tap 与 AppKit 的会话状态必须同步，不能只改 reduce 而留下旧 tap 状态。

### 关闭窗口

按 ⌘D 固定目标身份，后台请求该窗口的 AX close button press，绝不向 app 发送 quit/terminate。目标匹配必须唯一；匹配有歧义或无关闭按钮时反馈失败，不猜测、不关闭别的窗口。

CRT 仅作用于卡片预览：垂直收缩为亮线 → 水平收缩为亮点 → 轻微闪烁消失，总时长初定约 450ms。关闭请求与动画启动并行；只有实际窗口消失且动画完成，才从列表移除并选下一项（末项则前一项）。若失败或窗口等待保存确认，恢复预览，不假装已关闭，不自动处理保存对话框。长按的系统按键重复不触发连关；同一目标关闭请求在途时不重复发送。关闭期间暂不接受导航和再次关闭，Esc、打开设置与停用仍有效。⌘ 模式中按 ⌘D 转为保留模式，随后松开 ⌘ 不会意外激活另一窗口。Esc / 设置 / 总开关关闭可随时结束面板会话，旧动画回调不能影响新会话。

## 验收标准

1. 预览图四角清晰可见为圆角，内容没有漏出直角，高亮底色圆角与预览留白协调；图标回退保持相同几何。
2. 未分组时，0、1、3、5 项面板同宽同高；6 项第二排；过滤到 1 项宽度不缩；窄屏不溢出。
3. 分组开启两 app 分两区，标题带图标；同 app 六窗排两行。上下方向跨真实行，空槽不成为选中项。
4. 快速连续 Tab 指示条不积压、不跳回旧位置；换行不穿过图片；Reduce Motion 下无 CRT 闪烁。
5. 总开关关闭恢复系统 ⌘Tab；菜单栏仍能打开设置；重新开启正常。重启保留设置。
6. English 默认；切换中文后所有应用自有界面一致，重开应用仍为中文。
7. 登录项开关与系统状态一致；需要批准/注册失败不显示假成功。
8. ⌥Tab 松手再按 ⌘ 面板保留；⌘,、⌘F、⌘D 正常。结束会话后再次唤出正常。
9. ⌘D 只关闭目标窗口；CRT 三阶段正确；高亮落在存活相邻项。关闭最后一项为空态。
10. 保存确认、同标题重叠窗口、关闭失败、目标已消失、连按、动画中 Esc/重新唤出均不关闭错误窗口、不丢真实卡片。
11. About 版本 0.0.5，仓库链接正确；scripts/test 与 CI 通过，人工项目与自动化结果分开记录。

## 未决问题

- 「少于五个窗口面板大小不变」与「每 app 独立新行」在分组模式有冲突：例如三个 app 各一窗，需要三组而非一行。目前提案是所有模式固定宽度，未分组 0–5 项固定一行高度，分组则按区增高并滚动；此处仍待确认。
- 动画时长/阻尼、预览与面板圆角是提案值，需真机体验调校；原型用于比较视觉，不作为系统行为证据。
- 窗口关闭成功由真实窗口消失确认，AX 接受请求不等于关闭完成。待保存确认时恢复卡片并引导用户处理目标应用；具体等待时限在实现时验证，不无限等待，也不自动选择“丢弃”。
- 新版本默认语言英文是明确需求；窗口本身的标题及 app 名保留原始内容，不翻译。
