# slime v0.0.8

Faster panel opening, reusable window previews, more reliable window switching, and in-app updates.

## Changes

- Show the panel immediately, retain previews across openings, and update changed windows in the background. Reuse search cards and reduce repeated preview work. ([#84](https://github.com/chriscco/slime/pull/84)) — @chriscco
- Keep Command/Option-Tab working after dismissing the panel with Escape while still holding the modifier. ([#82](https://github.com/chriscco/slime/pull/82)) — @chriscco
- Close Settings with Command-W, refresh About with a rounded banner, and add opt-in update checks with confirmed installation. Improve permission prompts and accurately show whether slime is enabled after permission denial. ([#76](https://github.com/chriscco/slime/pull/76)) — @chriscco
- Choose Liquid Glass or a solid panel background, with a solid fallback and experimental macOS 15 support. ([#78](https://github.com/chriscco/slime/pull/78)) — @chriscco
- Choose normal cached previews or captures that can show tilted Stage Manager windows. Improve Appearance spacing and filter unconfirmed duplicate windows. Both modes now retain previews across openings; Fresh captures do not save images to disk. ([#75](https://github.com/chriscco/slime/pull/75)) — @chriscco
- Switch to the selected individual window, update window titles, and order windows by recent use with the current window first. Fall back to the application when an individual window cannot be targeted reliably. ([#80](https://github.com/chriscco/slime/pull/80)) — @chriscco

## Installation

Download `slime-0.0.8-arm64.dmg`, open it, and drag slime to Applications.
Requires Apple silicon; macOS 15 support is experimental. Liquid Glass requires macOS 26 or later.

The app is self-signed and not notarized by Apple. If macOS blocks opening, use
**System Settings → Privacy & Security → Open Anyway**. Allow Accessibility access;
Screen Recording access enables window previews. Restart slime after granting permissions.

Upgrading from 0.0.7 requires this manual installation. Version 0.0.8 introduces
in-app update checks for subsequent releases, available in **Settings → About**.

## Known limitations

- Some minimized, offscreen or other-Space windows cannot provide a preview; slime keeps an available preview or shows a placeholder.
- Previews are snapshots, not live video. Background contents may remain temporarily out of date.
- macOS 15 has automated compatibility checks but has not completed the full native permission and window-operation acceptance matrix.
