# 0.0.7 validation

Development validation on 2026-10-15; not a release certification.

## Automated

- `scripts/test`: 177 tests passed after the initial feature tests failed as expected.
- `scripts/build-app`: debug bundle built and signed with the existing local certificate.
  `codesign --verify --strict` passed; bundle reports 0.0.7 and contains slime.icns.
- Tests cover theme fallback/persistence, exact deep-blue RGB, fixed/system resolution,
  actual inherited application appearance changes, preserved query/focus/selection,
  hint/status priority, long-query geometry, preview selection and scroll reachability.
- Existing trigger, close, grouping, and thumbnail tests remain included.

## Native visual checks

- A disposable copy of the source rendered all four panel palettes, focused and
  unfocused search, and English/Chinese settings with synthetic windows. No test
  entry point is present in the product source or app bundle.
- Inspected white focused search and deep-blue unfocused search: readable labels,
  unclipped logo, hint, and fallback previews; five-column geometry unchanged.
- Captured an on-screen native settings window: all four previews render fully,
  names sit below the mini-panels, and System displays a split light/dark preview
  plus a selection checkmark. The first capture exposed intrinsic button-height
  compression; a regression assertion now enforces the intended 102 pt height.
- Scrolling to the final control, selection persistence, native accessibility role
  and value, and three header widths (320/600/1088 pt) are automated checks.
- The fixture renders the same bundled icns artwork, but does not certify production
  keyboard interception or glass composition over the user's real desktop.

## Header and theme-click follow-up

- Regression tests reproduced non-trackable native button-cell regions before the
  fix; preview, center, and caption points now hit the button and its trackable cell.
  Existing action tests verify preference changes and selection state.
- Header tests cover shared preview alignment, rounded logo clipping, transparent
  shortcut text, and primary text resolving bright in Dark Aqua and dark in Aqua.
- Inspected updated native black and white renders: logo rounding, header alignment,
  readable unfocused text, and no separate shortcut background.
- End-to-end mouse clicking remains unverified: the disposable event fixture did not
  activate its window reliably, and native GUI automation failed to start its pipe.
  Cell-hit tests are not a substitute for owner acceptance in the running app.

## Remaining owner acceptance

- Launch the rebuilt app and verify logo loading and real Command-Tab / Option-Tab /
  Command-F / direct-typing behavior, including caret, status, and focus transitions.
- Compare glass strengths 0/0.2/1 over real desktops, System changes while visible and
  hidden, light/custom-accent contrast, and Reduce Motion.
- Verify keyboard navigation through settings previews, VoiceOver announcements, and
  scrolling in both settings appearances on the owner's display.
- No end-to-end frame-time, idle-CPU, Space/Stage Manager, or multi-display performance
  measurement was added; existing platform acceptance gaps remain explicit.

## Limits

No new release, DMG, notarization, or performance claim. Physical keyboard interception,
Space/Stage Manager behavior, screen composition over varied desktops, and all real
hardware combinations require manual acceptance; unit tests do not certify them.
