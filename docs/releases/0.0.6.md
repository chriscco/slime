# slime 0.0.6

Release notes prepared for publication after the implementation is merged and the [release acceptance checklist](0.0.6-validation.md) is complete. Publication is tracked in [#52](https://github.com/chriscco/slime/issues/52).

## Changes

- Slime green (`#96D76A`) is the default accent throughout the panel and settings. Existing saved accents reset once; later custom colors persist.
- The supplied slime artwork is now the application icon.
- Command-D can reveal an inaccessible window and retry after fresh identity checks. It closes only the selected window, leaves its app running, and never answers save dialogs. After an application handoff, slime stays dismissed.
- Selected tint, window title, and underline fade during CRT. Failed direct closes restore them, and confirmed removal animates panel height when rows disappear.
- Command-F visibly focuses the rounded search field. Its end caret follows typing and Backspace; Reduce Motion disables caret travel and panel resizing.
- Close work shares a three-second deadline and cancellation token. Refresh requests coalesce, thumbnail disk loading/decoding runs off the main thread, and unchanged previews are reused.
- Bilingual READMEs include installation instructions and repository trees; module design, decision, and handoff documents are in English.

## Install

Requires macOS 26+ and Apple silicon. Download `slime-0.0.6-arm64.dmg` and `slime-0.0.6-arm64.dmg.sha256`, then run:

```sh
shasum -a 256 -c slime-0.0.6-arm64.dmg.sha256
```

Open the image, drag slime to Applications, eject the image, and launch slime. This release is locally self-signed and **not notarized**. If macOS blocks first launch, follow the per-app **Privacy & Security → Open Anyway** procedure in the [README](../../README.md#install-the-dmg). Accessibility permission is required; restart after granting it. Screen Recording enables previews but is optional.

## Limits

Public Accessibility information can be incomplete across Spaces. Ambiguous close targets are refused. Offscreen previews may be stale, and externally closed windows may take time to disappear when macOS retains their surfaces. Save dialogs remain under user control. Search supports append/Backspace with an end caret, not arbitrary text editing or IME composition. Secure Input falls back to the system switcher. Intel and notarized artifacts are not included.

## Publishing

From the verified user-merged commit: run `scripts/test` and `scripts/package-dmg`, verify the current commit's CI, and tag it `v0.0.6`. Attach the DMG and its generated SHA-256 file to the release using these notes. Download the published files and check their checksum again. Never reuse the pre-merge candidate as the final release artifact.
