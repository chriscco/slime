# Fresh previews implementation plan

Goal: selectable cached/fresh previews without slowing panel input.
Architecture: keep WindowThumbnails as the single capture owner; add explicit session
boundaries and a persisted Settings preference. Fresh mode bypasses disk operations,
accepts perspective images, and deduplicates requests within a session.
Constraints: macOS 26, public ScreenCaptureKit only, cached default, 300 ms presentation
limit, no captures caused by search/selection, no stale-mode writes or images.
