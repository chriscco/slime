# slime v0.0.8

Unreleased.

## Changes

- Close Settings with Command-W, refresh About with a rounded banner, and add opt-in Sparkle update checks with confirmed installation and signed release metadata. Use only the macOS Accessibility permission prompt when enabling slime without access, without an extra slime alert or forced Settings navigation. Keep Settings from covering permission dialogs, and preserve default-enabled startup after missing permission while showing the actual enabled state after denial. ([#76](https://github.com/chriscco/slime/pull/76)) — @chriscco
- Fix unattended release signing on hosted runners, limit certificate import time, and verify signing with disposable test credentials in CI. ([#68](https://github.com/chriscco/slime/pull/68)) — @chriscco
- Require every PR to update the current unreleased notes with its changes, PR link, and author credit; keep frozen versions unchanged and begin the 0.0.8 changelog. ([#70](https://github.com/chriscco/slime/pull/70)) — @chriscco
- Add selectable Liquid Glass and solid panel backgrounds, with an opaque fallback and experimental macOS 15 support; keep single-scope specs with their implementation PRs. ([#78](https://github.com/chriscco/slime/pull/78)) — @chriscco
- Add a bilingual preview-source preference with cached previews by default and session-scoped fresh captures that skip stored previews, retain usable perspective images, and discard stale capture results; document measured cached/fresh performance with Stage Manager enabled in both READMEs. Separate the preview-source explanation from theme cards, and filter unconfirmed same-title offscreen duplicates while retaining previously observed windows. ([#75](https://github.com/chriscco/slime/pull/75)) — @chriscco
