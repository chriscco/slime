# slime v0.1.0

Unreleased.

## Changes

- Support Chinese composition and native search editing, including selection, clipboard actions and per-session undo/redo. Candidate keys stay with the input method, empty-result Enter keeps the search open, and clicking a card switches to that window. ([#103](https://github.com/chriscco/slime/pull/103)) — @chriscco
- Center search text and use a rounded insertion caret that is white on dark themes and black on light themes. ([#103](https://github.com/chriscco/slime/pull/103)) — @chriscco
- In focused search, Left/Right move the caret and Esc first goes to active composition. Unbound Command/Option combinations use native editor behavior instead of adding query letters. Restore the empty-search hint when reopening after typing. ([#103](https://github.com/chriscco/slime/pull/103)) — @chriscco
- Customize the search and window-title font with system, system monospace, Hack, Menlo, Monaco or Courier New, plus independent 12–20 pt size controls. Named fonts must be installed locally. ([#105](https://github.com/chriscco/slime/pull/105)) — @chriscco
